欢迎来到“类脑 (ΟΔΥΣΣΕΙΑ)”GitHub 组织。这里是类脑角色卡论坛相关项目的开源代码库与文档托管中心。

## 关于组织

类脑是一个专注于大语言模型角色扮演（LLM Roleplay）衍生生态的社区论坛。
本组织建立的初衷，是为了将论坛及卡区生态的核心研发进行集中管理与开源共享。目前相关项目正处于早期筹备与架构设计阶段。

---

## 规划项目

本组织后续将逐步开源并维护以下核心模块：

* **论坛前后端**：用于构建类脑社区日常交流、用户互动与板块管理的论坛核心基础代码。
* **卡区前后端**：专为角色卡（Character Card）生态设计的展示、分享与检索区域，包含对角色卡元数据（如 PNG 隐写数据、JSON 配置）的解析与管理功能。
